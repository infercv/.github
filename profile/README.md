# Infer.cv

### Computer Vision for Your App

Add ready-to-use computer vision capabilities to your applications without managing models, runtimes, or inference infrastructure.

**On-device when supported. Cloud when needed.**

Infer.cv is building a developer platform for image and video understanding, with versioned capabilities, structured outputs, and a consistent interface across supported execution environments.

### What we're building

- **Vision Capabilities**: Ready-to-use, versioned capabilities for common computer vision tasks.
- **Device & Cloud Inference**: Run on supported devices or use cloud execution when needed.
- **Developer SDKs**: Integrate vision capabilities using familiar programming languages and frameworks.
- **Infer Elements**: Reusable UI components for vision-powered applications.

### Open Source

We're preparing our developer SDKs, reusable Elements, and integration examples for public release.

Repositories will be published here as they're ready.
